# 🎙️ Projeto: Podcast via IA, Projeto [DIO](https://web.dio.me/track/microsoft-50-anos-prompts-inteligentes) – *O Labirinto das Linhas*

Bem-vindo ao **O Labirinto das Linhas**, um projeto inovador de criação de podcasts proposto pela DIO com o [Felipe Aguiar](https://github.com/felipeAguiarCode) como guia. 
Meu podcast tem a temática sobre tecnologia e aprendizado de programação, impulsionado por inteligência artificial. A proposta seria explorar autoaprendizagem em linguagens de programação e inglês técnico, trazendo um formato leve e dinâmico com curiosidades e dicas úteis para iniciantes.

## 🚀 Objetivo
Este projeto busca democratizar o acesso ao conhecimento técnico, permitindo que qualquer pessoa possa aprender e se aprofundar em tecnologia de forma acessível e envolvente. A IA auxilia na elaboração dos roteiros, estruturação dos episódios e até mesmo na criação de conteúdo visual para o podcast.

## 🧩 Estrutura dos Episódios
Cada episódio segue um formato curto e objetivo, com os seguintes blocos:
- **Introdução**: Estilo narrativo inspirado em Lewis Carroll, trazendo um toque de criatividade ao tema.
- **Curiosidade 1**: Fatos interessantes sobre HTML.
- **Curiosidade 2**: Ferramentas para facilitar a programação.
- **Curiosidade 3**: Dicas para melhorar o inglês técnico.
- **Finalização**: Encerramento dinâmico com o lema: *Eu sou a Samara e esse foi 3 coisas impossíveis antes do café da manhã.*

## 🛠️ Tecnologias Utilizadas
Este projeto integra diferentes ferramentas e linguagens para tornar a produção do podcast eficiente e automatizada:
- **[Microsoft Copilot](https://copilot.microsoft.com/)** para estruturação dos roteiros.
- **[ElevenLabs](https://elevenlabs.io/app/home)** para transformação do texto em áudio.
- **Markdown** para documentação e formatação de conteúdo.
- **GitHub** para colaboração e versionamento.
- **Visual Studio Code** como ambiente de desenvolvimento.
